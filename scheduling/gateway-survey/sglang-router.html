SGLang Router（sgl-router）功能实现讲解

Slim、KV-aware、OpenAI 兼容的 SGLang 单模型 router（Rust）。能力标注：⚠️ 块级KV感知（外部索引器）✅ 前缀缓存感知✗ 多实例HA同步✗ Token负载感知

注意：这是新 sgl-router，与旧 sgl-model-gateway 不同。旧 sgl-model-gateway 与 SMG 同源（繁重的多模型 gateway）；新 experimental/sgl-router 是 SGLang 重新实现的 slim、单模型、KV-aware router，做了升级。目前仍位于 sgl-project/sglang 仓库的 experimental/sgl-router 目录（社区有 discussion 提议独立成单独仓库，尚未完成）。

块级 KV 感知（⚠️）—— external KV indexer

新 sgl-router 的升级点：支持外部 KV 索引器作为 cache-aware 信号源。配置 --policy cache_aware_zmq + --kv-indexer-endpoint 后，Indexer 替代 Router 本地的 radix tree 作为 cache 信号——这是块级 KV 感知（外部索引器维护引擎的真实 KV 块状态）。

sgl-router \
  --model-id qwen3 \
  --worker-urls http://10.0.0.1:30000 http://10.0.0.2:30000 \
  --policy cache_aware_zmq \
  --kv-indexer-endpoint http://10.0.0.10:50051 \
  --kv-indexer-query-timeout-ms 100 \
  --kv-indexer-query-max-inflight 32
  • 复用了已有的 cache-aware 策略和阈值；配置后 Indexer 替换本地 radix tree 作为 cache 信号。
  • 查询成功但无可用匹配 → 按最小活跃负载选；连接失败/超时/拒绝 → 直接 503（不静默切换信号）。
  • 标注 ⚠️ 而非 ✅：需要外部部署 KV indexer，是可选的（默认仍是本地 radix tree）。
来源：experimental/sgl-router README（"External KV indexer as the cache-aware signal source"）

前缀缓存感知 —— 本地 radix tree（默认 cache_aware）

默认 cache_aware 策略沿用旧实现：本地 radix tree 前缀匹配 + 负载平衡阈值（--cache-threshold 0.3、--balance-abs-threshold、--balance-rel-threshold）。不配 external KV indexer 时就是这一层。

来源：同上 README（"The existing cache-aware policy and thresholds are reused"）

服务发现 + PD 分离

  • Worker 池：静态 URL 列表，或 K8s EndpointSlice 自动发现（--service-discovery + --selector app=engines-qwen3）。
  • PD 分离：--prefill-selector / --decode-selector 分开发现 prefill/decode worker。
  • 单模型：--model-id 必填，一个 router 实例服务一个模型。
  • 端点：/v1/tokenize、/v1/detokenize、/v1/models、/v1/chat/completions（buffered + SSE）、/healthz、/readyz、/metrics。
来源：同上 README（"Running" / "Kubernetes EndpointSlice discovery"）

多实例 HA（✗）

新 sgl-router 是单实例设计（一个实例服务一个模型），无跨实例路由状态同步。多副本部署时各自独立，cache 命中会退化（与旧 sgl-model-gateway 的 radix tree 不同步问题一致）。

小结

新 sgl-router 把旧 sgl-model-gateway「瘦身」为 slim 单模型 router，并加了两个升级：EndpointSlice 服务发现 和 external KV indexer（块级 cache 信号）。定位从「多模型网关」收敛为「SGLang 引擎的轻量 KV-aware 前置 router」，块级感知靠外部索引器（可选）。
