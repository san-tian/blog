SMG（Shepherd Model Gateway）功能实现讲解

引擎无关的高性能路由 Gateway（Rust）。能力标注：✅ 块级KV感知（精确镜像）✅ 多实例HA✅ 多后端✗ Token负载感知

同源说明：SMG（lightseekorg/smg，原 psrl-project/smg）是一个通用 Rust LLM router 框架，被 vLLM 采用为 vllm-router，也曾被 SGLang 采用为（旧的）sgl-model-gateway——三者的调度策略（cache_aware / power_of_two / consistent_hash 等）是同一套代码。注意：SGLang 新的 experimental/sgl-router 是重新实现的 slim KV-aware router，与 SMG 不同源。见 SGLang Router 和 vLLM Router 子页面。

块级 KV 感知 —— 精确镜像后端 KV cache

SMG 的 cache_aware 策略（8 种之一，默认）维护一棵 radix tree，但它是后端 KV cache 结构的精确镜像——文档原话 "exact replica of each backend's KV cache structure, enabling 100% accurate prefix match calculations"：

  • 同 token / 同分页 / 同驱逐策略：使用与后端调度器（SGLang / vLLM / TRT-LLM）完全相同的 token 表示、page size（如 FlashInfer 16 token）、驱逐策略（LRU / LFU / FIFO 等），所以前缀匹配 100% 准确。
  • 两种树：StringTree（HTTP，raw text）+ TokenTree（gRPC，token ID）。
  • Event-Driven Block Size：当 worker 上报 KV cache 事件时，cache-aware 策略从事件流学习实际 block size（优先于 --block-size 默认值）——这是块级 KV 事件感知。
  • 阈值参数：--cache-threshold（0.3，前缀匹配比例门槛）、--balance-abs-threshold（64）、--balance-rel-threshold（1.5）——负载失衡才 rebalance（「粘缓存直到失衡」，与 llm-d sticky-until-saturated 同思路）。

效果：文档报告 TTFT p50 降 70%、p99 降 75%，cache hit 率 0%→65%。

来源：SMG Cache-Aware Routing 文档（"Radix Tree Mirroring" / "100% Backend Synchronization" / "Event-Driven Block Size"）

多实例 HA —— SWIM gossip + CRDT（最完整）

SMG 是 9 个 gateway 里多实例同步最完整的：

  • SWIM gossip 协议：1s 心跳 ping/ping-req，自动 peer 发现，秒级故障检测（INIT→ALIVE→SUSPECTED→DOWN→LEAVING）。
  • CRDT 存储：G-Counter（请求计数）、PN-Counter（token bucket）、LWW-Register（worker 状态）、OR-Set（worker 集合），无协调锁、分区容忍、自动冲突解决。
  • 同步的状态包括 cache-aware routing tree 本身：radix tree 操作、前缀匹配数据、LRU 驱逐协调都跨节点同步——这是唯一把「KV 路由树」纳入跨实例同步的方案，保证任一 router 处理请求时缓存路由决策一致。
  • 3 节点容忍 1 故障、5 节点容忍 2 故障；支持 K8s StatefulSet + headless service + pod discovery。
来源：SMG High Availability 文档（Gossip Protocol / State Synchronization / CRDT Implementation）

多后端

自托管引擎（vLLM、TensorRT-LLM、TokenSpeed、SGLang、Ollama、任意 OpenAI 兼容）+ 云提供商（OpenAI、Anthropic、Gemini、Bedrock 等），统一 OpenAI 端点。

来源：SMG README（"Supported Backends"）

其他能力（不在 7 维对比内，但值得一提）

  • gRPC 流水线：原生 Rust tokenization、reasoning parser、tool call 解析，亚毫秒路由决策、zero-copy tokenization。
  • 可靠性：熔断（Closed/Open/Half-Open）、指数退避重试 + jitter、token bucket 限流 + 排队。
  • WASM 插件：沙箱内自定义请求/响应逻辑。
来源：SMG README（Features 表）

小结

SMG 的定位是「引擎无关 + 企业级路由 + 最强多实例 HA」：HA 同步用 SWIM+CRDT 做到了包括 cache-aware 路由树在内的全量状态跨副本一致；KV 感知是精确镜像后端 KV cache（100% 前缀匹配准确）+ KV 事件学习 block size，块级精确度与 Dynamo/llm-d 相当，但实现方式不同（主动镜像复刻 vs 被动事件订阅）。
